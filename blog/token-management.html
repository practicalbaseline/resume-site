Token management

Every LLM call costs tokens. Treat the context window as finite from the start.

Basics

~1 token per 4 characters. Input and output both count. Output usually costs more.

Do this

  • Count tokens before you ship (tiktoken)
  • Put important instructions at the start and end of prompts
  • Summarize old conversation history, keep recent messages verbatim
  • Retrieve relevant chunks for RAG — don't dump the whole knowledge base
  • Set max_tokens on every completion
  • Put static prompt content first for caching
  • Route simple tasks to smaller models

Red flags

  • Prompts that grow forever with chat history
  • No output token limit
  • Frontier model for trivial tasks
