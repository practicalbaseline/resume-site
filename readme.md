# itsjakegray.com

A still, dark page that says "Website coming soon."

**https://itsjakegray.com**

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Static output lands in `dist/`. Vercel publishes `main`.

## Pictures

`public/resume-images/` is a public shelf. Read `public/resume-images/README.txt` before adding a file. Strip personal details out of a picture before it is saved here.

## Stack

- Vite + TypeScript
- One static page
